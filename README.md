# GOLF GUTS PUTT LAB

スマホをグリーンに置いて傾斜を測り、カップまでの距離から「狙う幅（カップ何個分）」と「必要な振り幅」を表示するパッティング練習用Webアプリです。90 BPM・3/4拍子のメトロノーム付き。

- 公開ページ: リポジトリ直下の `index.html`（GitHub Pages で配信）
- 傾きセンサーは https で開いたときだけ使えます。使えない環境では手動入力に切り替わります。
- 表示はすべて推定値です（測定地点の傾斜がカップまで一定と仮定）。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | 公開される完成ファイル（`build.py` が生成） |
| `src/physics.js` | 計算ロジック（ライン・狙い幅・振り幅） |
| `src/app.js` | 画面・センサー測定・メトロノーム |
| `src/style.css` / `src/body.html` | デザインと画面構成 |
| `test/` | 計算の単体テストと、ブラウザでの操作テスト |

## 更新手順

```
python3 build.py          # src/ から index.html を作り直す
node test/physics.test.js # 計算のテスト
```
